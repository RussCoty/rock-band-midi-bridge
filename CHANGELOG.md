# Changelog

## 1.2.0 — first public release

- Native macOS app with a clearer connection display, readable controls, setup guide and keyboard icon.
- Universal Apple Silicon / Intel app bundle for macOS 13 and later.
- Wii Rock Band 3 keyboard HID decoding: 25 keys, velocity, touch CCs, pitch bend and digital sustain.
- Selectable CoreMIDI output, remembered routing and output refresh.
- Dedicated IAC routing instructions for Pro Tools.
- Note release on panic, route/settings changes, disconnect, timeout and quit.
- Thirteen decoder tests; verified physical-key MIDI and IAC routing on Apple Silicon.

Earlier 1.0/1.1 builds were local development versions.
